# أكّد TV — AKKAD

تطبيق IPTV عربي بهوية فضائية زرقاء وبنفسجية. نسختان منفصلتان: **مستخدم أفقي** (`/tv`) و**إدارة** (`/admin`). الخادم Node.js، البيانات والصلاحيات Supabase، وتشغيل الوسائط عبر بوابة الخادم.

## وضع الدخول
- **VIP:** اسم مستخدم وكلمة مرور أنشأتهما الإدارة. يعرض كل مزودي Xtream النشطين المسموحين بهذا الاشتراك.
- **التفعيل بالكود:** كود واحد لعامة المستخدمين، يفتح كامل محتوى مزود واحد مرتبط بهذا الكود حصراً، بلا مزامنة يدوية ولا اختيار مزود.

لا يحتوي التطبيق على قسم أنمي مستقل.

## واجهة المستخدم
`public/tv.html` + `public/akkad.js` للمصادقة والمحتوى والتشغيل، `public/orbit-tv.css` و`public/orbit-tv.js` للهوية الجديدة والمفضلة والرياضة وجدار القنوات. شعار المستخدم في `public/orbit-logo.svg`. لوحة الإدارة ومستودع البيانات لم يُستبدلا.

## تطبيق Android TV
يوجد مشروع Gradle أصلي في `android/` يستخدم شاشة أفقية ثابتة ومشغل Media3. راجع `android/README.md`. العمل التجريبي يُبنى في GitHub Actions كـ APK للاختبار؛ الإصدار النهائي يتطلب توقيع إنتاج ثابتاً في بيئة آمنة.

## التشغيل
```bash
npm install
npm test
npm start
```

ثم افتح `http://localhost:3000/tv` و`http://localhost:3000/admin`.

## بيئة الخادم
يجب ضبط `SUPABASE_URL`، `SUPABASE_PUBLISHABLE_KEY` و`SUPABASE_SERVICE_ROLE_KEY` و`AKKAD_SOURCE_ENCRYPTION_KEY` و`AKKAD_USERNAME_SECRET` في إعدادات الخادم، وليس داخل GitHub أو HTML أو APK.
تُستخدم `AKKAD_ALLOWED_SOURCE_HOSTS` لتقييد النطاقات المصرح بها للمزودين، مع تفعيل HTTP الاختياري من الخادم فقط. لا تستخدم حسابات أو روابط بث إلا مع صلاحية قانونية.

الإعدادات الحقيقية، وصلاحية كل كود واشتراك، وحسابات مزودي IPTV تُفحص من الخادم. لا تُعد حماية واجهة المستخدم أو ملف APK بديلاً عن تحقق الصلاحيات على الخادم.
