# مسار تطبيقات Android الأصلية

تُنفّذ في مرحلتها الخاصة؛ الواجهتان الحاليتان ضمن `public/` تعملان كواجهات ويب مؤقتة للربط واختبار API.

## المستخدم (Landscape)
Package المقترح `iq.akkad.tv`، Android Kotlin، Media3/ExoPlayer للبث المباشر والأفلام والمواسم؛ دعم التنقل بالريموت والترجمة والصوتيات، قنوات صوت متعددة، ومشاهدات VIP.

## الإدارة (Portrait)
Package المقترح `iq.akkad.control`، Android Kotlin أو لوحة الإدارة الويب كتطبيق PWA متجاوب؛ العمليات الإدارية تحصل على الخادم فقط، مع أدوار وصلاحيات مستقلة.

## التوقيع
يتم إنشاء keystore إصدار ثابت داخل بيئة البناء الآمنة، مع نسخ احتياطي خاص. **ممنوع** رفع مفاتيح التوقيع إلى المستودع.
