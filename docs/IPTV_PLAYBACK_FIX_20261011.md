# AKKAD — إصلاح التشغيل ونسختا الاختبار (2026-10-11)

## ما تم اكتشافه
أظهرت سجلات Railway استجابات HTTP 302 لطلبات `/api/media/[ticket]`، وكانت بوابة الوسائط ترفض التحويلات وتعيد HTTP 502. عدد القنوات والأفلام والمسلسلات لا يثبت أن التشغيل متاح.

## إصلاحات المسار
1. السماح بتحويلات HTTP 301/302/303/307/308 إلى خادم وسائط عام بعد فحص DNS وحظر العناوين الداخلية؛ الحد الأعلى 5 تحويلات.
2. الاحتفاظ بمعلومات Range للتحميل الجزئي وإعادة كتابة روابط HLS المحمية الموجّهة إلى CDN.
3. دعم HLS.js وmpegts.js محلياً للمشغل على الويب، مع الانتقال إلى TS عند فشل HLS في القناة.
4. دعم Media3/ExoPlayer على أندرويد، مع محاولة TS بديلة للقناة بعد فشل HLS.
5. واجهة إدارية لطلب `POST /api/admin/sources/:id/probe` لتجربة عينة تشغيل من القنوات والأفلام وعد حلقات المسلسلات. تتطلب جلسة إدارة صالحة.
6. لا تُرسل كلمات مرور مزودي Xtream إلى المتصفح أثناء الاختبار؛ تُفك على الخادم فقط، والاستجابة تحتوي نتائج الفحص دون عناوين وسائط خاصة.

## إضافة مصادر HTTP
أُضيف النطاقان `clicktv1.live` و`servx.pro` كأسماء مصادر محتملة إلى `AKKAD_EXTRA_ALLOWED_SOURCE_HOSTS` على Railway، من دون إضافة حسابات أو كلمات مرور وهمية.
الموافقة على اتصال HTTP من نافذة إنشاء المصدر مطلوبة، إلى جانب خيار `AKKAD_ALLOW_HTTP_SOURCES=true` الموجود مسبقاً.
اكتب اسم المستخدم وكلمة المرور الحقيقيين، وافحص الحساب ثم اختبر تشغيل عينة حقيقية. في حال كان المزود لا يقبل اتصال Railway أو يحتاج مكوّناً صوتياً غير مدعوم، فلن يعالج ذلك تغيير التصميم وحده.

## الصلاحيات
- VIP: يتيح جميع المزودين النشطين المسموح بهم للحساب الفعّال.
- الكود المجاني: يتيح مزوداً واحداً مرتبطاً بهذا الكود فقط.
- حسابات Xtream التي تنشئها الإدارة: يمكن تحديد المزودين المسموحين لكل حساب من القائمة.
- جميع عمليات التشغيل تمر ببوابة الخادم وسجلات التحقق، والروابط المؤقتة لا تحل محل التحقق من الصلاحيات.

## مسار تسليم النسخ
`/tv` واجهة المستخدم الأفقي على الويب، و`/admin` الإدارة العمودية.
Android المستخدم: `android/app`، Android الإدارة: `android/control`.
يبني GitHub Actions ملفي APK للتجربة ويضعهما في Artifacts. توقيعهما Debug مؤقت وليس مفتاح تحديث إصدار الإنتاج.

## حدود التحقق
اختبارات Node وCI وتجميع APK تؤكد سلامة البناء البرمجي، لكنها لا تثبت نجاح بث كل حساب فعلي. يلزم التجريب بحساب مرخّص، وكود صالح، وفي كلتا النسختين على الجهاز الحقيقي.
