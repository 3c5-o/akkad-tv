# أكّد: تطوير لوحة الإدارة

الهدف لوحة عمودية متجاوبة، حالة مزودين متصلة أو معطلة، تنظيم المحتوى، حسابات يديرها المدير، إعداد TMDb آمن، وأكواد مصادر مجانية بعد التأكد من الترخيص.

حسابات المشاهدين تتطلب Supabase Admin API بالمفتاح السري على Railway فقط. المزامنة المجدولة تتطلب هوية خادم مأذونة ولا تبدأ دونها.
